# Wdownloader

Настольное приложение для сохранения видео и аудио с YouTube. Rust + Tauri v2, статический Astro и React для интерактивного интерфейса. Монохромный дизайн с чёрной, белой и системной темой, локальный шрифт Manrope, иконки [Keyline Icons](https://github.com/keyline-icons/keyline-icons) в четырёх стилях (скруглённые, острые и их двухтоновые версии).

## Запуск на Windows

Нужны Node.js 22.12+ (либо поддерживаемая Astro версия 24+), Rust stable, Microsoft C++ Build Tools и WebView2. См. [требования Tauri](https://v2.tauri.app/start/prerequisites/).

```powershell
npm ci
npm run desktop
```

При запуске приложение само устанавливает недостающие yt-dlp, FFmpeg/ffprobe и Deno из официальных GitHub-репозиториев. Python отдельно не нужен. Компоненты сохраняются в `%LOCALAPPDATA%/com.wdownloader.desktop/tools/`. Зависимости также ищутся среди ресурсов приложения, в `tools/` проекта и PATH.

При ошибке появляется предупреждение с причиной и кнопкой повтора. Ручная инструкция содержит официальные ссылки, имена нужных файлов и точный путь папки. После копирования файлов нажмите "Проверить компоненты". Повторная установка пропускает уже найденные компоненты. Загрузка имеет таймаут, архивы распаковываются во временную папку, новые бинарники проверяются запуском; yt-dlp дополнительно проверяется по SHA256.

Для подготовки офлайн-комплекта или обновления инструментов в проекте оставлен `npm run setup:tools`.

```powershell
npm run dev          # Интерфейс в браузере, без скачивания
npm run build        # Проверка TypeScript и сборка Astro
npm run desktop:build # Windows NSIS installer
cargo test --manifest-path src-tauri/Cargo.toml
npm test
```

Установщик появится в `src-tauri/target/release/bundle/nsis/`. Перед сборкой установщика выполните `setup:tools`: содержимое `tools/` включается в установку. Бинарники и установщик не подписаны цифровой подписью.

## Возможности

- Обычные видео, Shorts, ссылки youtu.be и записи завершённых трансляций.
- Получение названия, автора, превью, длительности и фактических разрешений через yt-dlp.
- Видео: MP4, MKV, WebM, MOV. Звук: MP3, M4A, WAV, FLAC, Opus, AAC, OGG/Vorbis.
- Выбор верхней границы разрешения до доступного исходного, настройка качества аудио.
- Встроенный видео- и аудиоплеер с реальной звуковой волной, громкостью, скоростью и повтором.
- Обрезка одного участка двумя границами: перетаскивание, установка кликом и точный ввод времени. Сохраняется только выбранный участок; для точного среза выполняется перекодирование.
- Собственный титлбар и элементы управления. Прокрутка ограничена рабочей областью под титлбаром.
- Последовательная очередь до 50 задач, прогресс дорожек, скорость, оставшееся время, обработка ошибок, отмена дерева процессов и повторная попытка.
- Выбор папки, открытие папки файла, метаданные, история с поиском и фильтрами.
- `Ctrl+L` переводит фокус в поле ссылки. Настройки хранятся локально, история хранится в каталоге данных Tauri.

## Как устроено

`src/components/App.tsx` управляет интерфейсом. Команды и события Tauri связывают его с `src-tauri/src/lib.rs`. Rust валидирует ссылки и параметры, запускает yt-dlp без shell, читает stdout/stderr и передаёт события `download-update`. yt-dlp вызывает FFmpeg для объединения и конвертации. Deno нужен yt-dlp для обработки JavaScript YouTube.

В браузере доступен только предпросмотр. Скачивание и выбор папки работают внутри Tauri. Неудачные или прерванные задачи можно повторить; `.part` файлы сохраняются для продолжения. При повторном скачивании того же видео в ту же папку существующий итоговый файл не перезаписывается. Прогресс относится к текущей дорожке: после видео начинается отдельное скачивание звука, затем объединение.

Предпросмотр готовит локальную облегчённую копию по кнопке. Для аудио извлекается настоящая волна; видео приводится к H264/AAC до 480p. Копии хранятся в папке кэша приложения. Готовые загрузки тоже можно открыть во встроенном плеере, включая форматы, которые WebView напрямую не воспроизводит.

MP4/MOV используют доступные MP4 + M4A дорожки, WebM использует совместимые WebM дорожки, MKV выбирает лучшее доступное сочетание. При отсутствии совместимого формата yt-dlp вернёт ошибку. Параметр разрешения ограничивает качество сверху, не увеличивает исходное видео. FLAC/WAV не восстанавливают качество сжатого источника; установка битрейта для них отключена. Коллекции и прямые трансляции пока не поддерживаются.

YouTube может ограничивать выдачу по IP, региону или запрашивать вход. Импорт cookies и обход ограничений в эту версию не входят. Если извлечение перестало работать, обновите инструменты через `npm run setup:tools`.

## Распространение

Приложение использует внешние инструменты с отдельными лицензиями. У скачиваемой здесь GPL-сборки FFmpeg есть требования к распространению и предоставлению соответствующих исходников. Перед коммерческим выпуском подготовьте полный комплект third-party notices, текстов лицензий и соответствующих исходников выбранной сборки. `tools/THIRD-PARTY.txt` содержит ссылки на проекты; это не заменяет комплект лицензий для выпуска.
