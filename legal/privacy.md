# Политика конфиденциальности

Редакция от 28 ноября 2026 года. Политика описывает работу настольного приложения Wdownloader. Страницы проекта на GitHub и сайты площадок действуют по собственным правилам.

## Что хранится на вашем устройстве

Приложение сохраняет настройки, выбранную папку, язык, оформление и отметку о принятии документов. История содержит ссылки, названия, параметры, статусы и пути к результатам. Для предпросмотра может сохраняться временная копия медиа и звуковая волна. Приложение не отправляет историю разработчику и не содержит встроенной аналитики или рекламных трекеров.

Если вы сами подключите сессию YouTube, приложение сохранит cookies YouTube в папке данных на вашем устройстве. Они нужны yt-dlp для запросов от вашей учётной записи. При работе создаются временные копии, которые удаляются после штатного завершения запроса. Файл сессии даёт доступ к аккаунту, поэтому не передавайте его другим людям и не прикладывайте к отчётам об ошибках.

## Куда идут сетевые запросы

При открытии ссылки приложение и yt-dlp обращаются к площадке и её серверам медиа и изображений. Они видят IP-адрес, параметры запроса и сведения, необходимые для доступа к выбранному материалу. При входе в YouTube окно открывает сайт Google, который обрабатывает данные входа по своим правилам. Сервер разработчика для этих запросов не используется.

Для получения и обновления компонентов приложение обращается к GitHub и репозиториям поставщиков. При включении SponsorBlock запросы идут к sponsor.ajay.app. Для показа отметок приложение отправляет первые четыре символа хеша идентификатора видео. Служба получает IP-адрес запроса. При сохранении с включённым SponsorBlock yt-dlp отдельно обращается к этой службе.

## Как удалить данные

Сессию YouTube можно отключить в настройках, историю очистить на её странице. При удалении Wdownloader можно выбрать удаление настроек, истории, кэша и компонентов приложения. Скачанные файлы и незавершённые загрузки остаются в выбранной вами папке. Документы доступны в настройках. Отметка об ознакомлении хранится локально.
